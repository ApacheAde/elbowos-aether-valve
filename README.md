# Aether Valve

Full-colour Python 3 neon pipe-dream arcade for [ElbowOS](https://x.com/ElbowOS).

Rotate copper conduits until the lime well seals into the gold drain.
Live pipes flare cyan. Click a tile or use arrows + space to turn it.

## Play

```
pip install -r requirements.txt
python3 aether_valve.py --play
```

## Record a 9:16 reel

```
python3 aether_valve.py --record
```
